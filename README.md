**THE WORLD TODAY — Tuesday, 17 November 2026.** The whole day's world news on one newspaper front page, in a single 1024×1024 image: Beijing confirms the first-ever Xi–Trump–Putin summit for Thursday in Shenzhen, Ukraine drops the road arch of Putin's Kerch Bridge into the strait while Russia answers against Kyiv's bridges, tankers burn in the Strait of Hormuz as the US–Iran war flares, four Western governments tell Israel to open Gaza's gates, and Yemen's army falls back on Aden — plus Japan's jet scramble, France's fourth weekend of protests and COP31 in the ALSO TODAY strip. Five illustrations were generated for the page and graded to a navy duotone in `compose.py` so the sheet reads as one printed newspaper; every headline is set in crisp program-rendered type so the picture explains itself. `main.py` deterministically writes the finished page to `/output/entry.png`.

## Run it

```sh
python3 main.py
```
